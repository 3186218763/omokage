# 动作标签由 LLM 标签先行决定，System One 只管表演情绪

虚拟人物要按句做离散动作（点头、摇头、歪头）并与正在说的台词对齐。候选有三：LLM 标签先行（复用说话语气管线）、System One（Jev/Kev）扩一个问题、表演情绪→动作池的规则映射。决定走 LLM 标签先行：动作语义与生成中的台词强耦合，只有流式输出的 LLM 看得到句级内容与时机；System One 轮末才拿到整轮文本，做不到句级对齐；规则映射与台词脱钩。这不解除「禁动作括号」——括号写进台词仍被剥除，动作走独立标签通道，不进可见文本、不被朗读。

## Consequences

- 表演分两层：表演情绪是持续底色（System One 判定），动作是离散事件（LLM 标签），动作叠加在底色上；动作缺席时舞台自然回落到底色，无需额外兜底路径。
- 标签语法与说话语气同族（句前内联 `【动作：点头】`），复用既有括号剥离与防泄漏清洗；每轮至多 2 个动作、不连续重复。
- 动作闭集受资产约束：皮套能播什么才允许标什么，程序化小动作兜底；要扩词表先扩资产或程序化曲线。
